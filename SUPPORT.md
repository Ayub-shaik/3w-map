# Getting help
- **How do I use it?** Read the [README](README.md) quick start and [`docs/method.md`](docs/method.md).
- **Question:** open an issue with the "question" label.
- **Bug or idea:** use the issue templates.
- **Security or conduct concern:** report privately, see [SECURITY.md](SECURITY.md).
This is a volunteer, best-effort project; there is no guaranteed response time.
