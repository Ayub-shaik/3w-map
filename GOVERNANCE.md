# Governance
3w-map is a small, maintainer-led project. The maintainer ([@Ayub-shaik](https://github.com/Ayub-shaik)) decides what merges, guided by one rule: **claims must be backed by data**. A change that adds or strengthens a claim needs evidence in `data/`; a change that weakens a claim for good reasons is always welcome.

- **Decisions** are made in public, in issues and pull requests, and recorded in the pull request description. Significant method changes are written up in `docs/`.
- **Becoming a maintainer:** sustained, high-quality contributions (code, data or review) over several months; an existing maintainer invites you.
- **Disputes:** discuss in the issue; if there is no agreement the maintainer decides and explains why.
- **Releases:** tagged from `main` with notes in [CHANGELOG.md](CHANGELOG.md).
